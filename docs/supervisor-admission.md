# Mandatory productive continuation admission

Productive autonomous follow-ups require an affirmative independent supervisor
`continue` decision. A working-model continuation is a proposal, not admission.
The supervisor's next step replaces the proposal; terminal decisions veto it.
Missing callbacks, disabled strategies, invalid/undefined responses and exceptions
do not preserve executable model plans. The proposed next step remains in the
existing blocked task checkpoint and recent diagnostic evidence.

Genuine bounded timed waits remain nonproductive scheduler checks. An independent
safe continuation can replace a deployment wait; actual pending dependencies,
original scope, deadlines, pause/stop, queue ownership and persistence barriers
still gate execution. API runs remain caller-driven one-shot operations and the
nightly experiment retains its separate authority. Authenticated explicit task
resume records host admission through the existing persisted receipt mechanism.

Restart and idle scheduling reuse the existing `recoveryAdmission` receipt rather
than trusting a retained `next` string. Legacy productive checkpoints require
independent assessment. Unavailable/exhausted recovery assessment now holds work
instead of constructing an executable reconciliation fallback. This is a local
admission hold, not evidence that the underlying operator mandate is completed.

Existing host-recorded transcript collection is retained; no new collector or
worker-controlled evidence selector is introduced. Deterministic tests exercise
real Harness + assessCompletion + bundled prompt, not classifier accuracy.
